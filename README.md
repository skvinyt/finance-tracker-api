# Finance Tracker API

REST API для управления личными финансами, написанное на Java (Spring Boot) с использованием PostgreSQL. 

Основная ценность проекта — реализация перевода денег между счетами с гарантией атомарности (ACID) и защитой от состояния гонки (race condition).

## 🛠 Стек технологий
* **Java 21**
* **Spring Boot 4.x** (Spring Web, Spring Data JPA)
* **PostgreSQL 18**
* **Flyway** (миграции базы данных)
* **JUnit 5, Mockito, MockMvc** (тестирование)
* **Gradle**

## ⚙️ Функциональность
* Управление пользователями и счетами (в планах).
* **Перевод денег между счетами** (POST `/api/transfers`).
* Запись истории транзакций (доход/расход) при каждом переводе.
* Валидация входных данных и обработка ошибок.

## 🧠 Ключевые технические решения

1. **Финансовая точность**: Для хранения денег используется `NUMERIC(19,4)` в PostgreSQL и `BigDecimal` в Java. Это исключает ошибки округления, свойственные `float`/`double`.
2. **Работа со временем**: Для хранения моментов времени используется `TIMESTAMPTZ` и `OffsetDateTime`, что позволяет не терять информацию о часовом поясе при переносе данных между серверами.
3. **Транзакции и блокировки**: 
   * Метод перевода обернут в `@Transactional` для обеспечения атомарности.
   * Для предотвращения race condition (когда два параллельных перевода могут привести к отрицательному балансу) используется пессимистичная блокировка `SELECT ... FOR UPDATE` (`@Lock(LockModeType.PESSIMISTIC_WRITE)`).
   * Для защиты от deadlock (взаимной блокировки) счета блокируются в строго определенном порядке (по возрастанию ID).
4. **Тестирование**:
   * **Unit-тесты** с Mockito для проверки логики сервиса (включая проверку недостатка средств).
   * **Интеграционные тесты** с `@SpringBootTest` и `MockMvc` для проверки всего пути запроса (включая реальную БД). Используется `@Transactional` для отката изменений после каждого теста.
